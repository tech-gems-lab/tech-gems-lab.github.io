# tech-gems-lab.github.io

Public policy pages for the tools published by Tech Gems Lab, served by GitHub Pages at <https://tech-gems-lab.github.io>.

| Page | URL |
|---|---|
| Index | <https://tech-gems-lab.github.io/> |
| Save2Notion Privacy Policy | <https://tech-gems-lab.github.io/save2notion/privacy.html> |

The Save2Notion privacy policy URL is the one declared in the Chrome Web Store Developer Dashboard. Its text is kept in sync with `store/privacy-policy.md` in the Save2Notion repository.

Each tool gets its own folder. Static HTML with one shared stylesheet; no build step. Edit a file, commit, and GitHub Pages republishes. Privacy questions go to this repository's issues, so no personal email is published.
